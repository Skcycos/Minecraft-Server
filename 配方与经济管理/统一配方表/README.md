# 统一配方总表 · 农夫乐事 × 万花筒烹饪

> 本表为 **kaleidoscope_compat UNITE 统一兼容模式**下的实际生效配方合并表。
> 服务器基准:**万花筒烹饪(Kaleidoscope Cookery)** — 统一物品以万花筒为准,农夫乐事对应配方已被 UNITE 数据包替换/禁用。

## 数据构成(共 840 条)

| 来源 | 数量 | 说明 |
|---|---|---|
| 万花筒烹饪 | 518 | 全量原始配方(统一基准,未被修改) |
| 农夫乐事(原始) | 282 | 未受 UNITE 影响的 FD 配方 |
| 农夫乐事(已修改) | 25 | 原料/产物已替换为万花筒统一物品(如 FD 番茄→KC 番茄、FD 面团→KC 生面团) |
| 农夫乐事(万花筒机器) | 15 | 新增:用万花筒机器(炒锅/汤锅/菜板)制作 FD 菜品 |

**已剔除**:UNITE 禁用的 7 个 FD 配方(羊肉排系、稻米、水面团)、失效的 2 个面包配方(作者 bug,由 Create 命名空间替代配方承接)、本服未装模组(immersiveengineering/silentgear)的 integration 配方。

## 列说明

| 列 | 含义 |
|---|---|
| 模组 | `万花筒烹饪` / `农夫乐事` / `农夫乐事(万花筒机器)` |
| 配方ID | 数据包内路径(可据此在 JEI/KubeJS 定位) |
| 产物 | 中文名 + 物品ID |
| 数量 | 单次产量 |
| 机器 | 使用的方块/机器(万花筒机器排前) |
| 原料 | 中文名 + 物品ID/标签;`任选其一:[...]`=多选一;`(除...)`=差值 |
| 附加参数 | 烹饪时间/经验/所需工具/掉落率/载体等 |
| 饥饿值 | 食物恢复的饥饿值(nutrition) |
| 饱和度 | 实际饱和度恢复(=饥饿值×饱和度系数×2);空=非食物或无该属性 |
| 效果(buff) | 食用获得的状态效果:效果名 + 等级 + 时长(概率标注);空=无效果 |
| UNITE状态 | `原始(统一基准)` / `原始` / `已修改(UNITE)` / `新增(万花筒机器)` |
| 备注 | 修改/新增说明 |

> **食物属性来源**:农夫乐事 `FoodValues` / 万花筒 `ModFoods` 字节码反编译提取(nutrition / saturationModifier / effects)。335/840 条配方为食物产物,含属性;其余为非食物(家具/设施等)。效果等级以罗马数字隐含(如「营养」= I 级,「饱腹代偿 1分20秒」为 I 级)。
