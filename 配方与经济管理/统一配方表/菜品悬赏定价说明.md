# 菜品悬赏定价表（T1 / T2 / T3）

明细 CSV：`菜品悬赏定价表.csv`（每行末尾有**完整计算过程**）  
原料价：`原料单价参考表.csv` + `BOUNTIFUL_BASE_PURCHASE_PRICES.md`

## 计算公式

```text
1. 整份原料成本 = Σ(配方中每个原料的单价)
2. 单个产物成本 = 整份原料成本 ÷ 配方产出数量
3. 理论价值 = 单个产物成本 × 难度系数 × 增益系数 × 通用池系数
4. 建议 unitWorth = max(1, ceil(理论价值))  // 向上取整，单位：铜币
```

| 参数 | 取值 |
|---|---|
| 难度 T1 | × **1.15** |
| 难度 T2 | × **1.65** |
| 难度 T3 | × **2.45** |
| 无 buff | × 1.00 |
| 轻度 buff（温暖/营养等） | × 1.15 |
| 强增益（抗火/急迫II/饱腹代偿等） | × 1.35 |
| 负面趣味 | × 0.85 |
| 悬赏池=通用池 | 再 × **0.95** |
| 原料价优先级 | 已定义悬赏价 → 本表猜想 → 关键词缺省 |

> 切片、切块、切肉等配方必须使用实际产出数量。不得把整个蛋糕、派、南瓜或熟肉的全部成本重复计入每一个切分产物。

## 注意

1. 非食物（刀、石磨、告示牌等）已尽量排除。
2. 「含猜想原料=是」的条目，原料价可改 `原料单价参考表` 后要求重算。
3. 大锅配方若把 6 块肉都算进代表配方，成本会偏高（防刷偏保守）。
4. 系统收购价应仍低于玩家商店零售价。
