# 通用食物悬赏（food_common_objs）

## 当前用途

`food_common_objs.json` 现有 **69** 项 T1 基础熟食与一步加工食物。该池只由厨师法令 `cook.json` 引用，农夫法令只收购 `farmer_objs` 中的农作物。

```text
农夫 farmer：farmer_objs
厨师 cook：food_common_objs + food_t2_objs + food_t3_objs
```

## 定价规则

- `1 unitWorth = 1 铜币`。
- 多产出配方先用整份成本除以产出数量，再计算加工价。
- 切片、切块和切肉的价值不得高于原物品数倍。
- 价格详见 `菜品悬赏定价表.csv`，实际运行值以 `Server/config/bountiful/bounty_pools/food_common_objs.json` 为准。

2026-08-04 经济审查已修正南瓜片、蛋糕/派切片、熟肉切分、海带寿司切片等多产出溢价。

## 奖励

厨师使用铜/铁币池 `_all_rews` 与厨师金币池 `gold_currency_rews`。金币奖励为 1～6 枚、声望10、低权重。

## 同步

修改悬赏池后运行：

```bash
python3 配方与经济管理/统一配方表/scripts/sync_bounty_economy.py
```

该脚本会同步 KubeJS Tooltip 注册表并检查目标池基础结构。
