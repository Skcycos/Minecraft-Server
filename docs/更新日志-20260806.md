## 🎉 重头戏：TCTH 职业模组 0.2.0（自研模组）

### 🍳 新职业：厨师（tcth:chef）
- **统一烹饪事件**：原版合成/熔炉、农夫乐事（Farmers Delight）烹饪锅、万花筒烹饪（Kaleidoscope Cookery）锅/汤锅/蒸笼——七种烹饪设备全部纳入一套奖励体系。
- **料理等级体系**：数据驱动三档料理——**简餐 / 家常 / 珍馐**，互斥分档。
- **厨师能力树（四条路线）**：
  | 路线 | 效果 |
  |---|---|
  | 庖厨研修 | 职业经验 ×1.25 / ×1.5 / ×2 |
  | 刀工 | 厨刀不耗耐久的概率 10% → 20% → 35%（入门/游刃有余/庖丁解牛） |
  | 炉火 | 火焰伤害减免 15% → 50% → 30%（熟悉灶火/掌控炉温/炉火纯青） |
  | 品鉴 | 吃正餐获得增益：生命恢复Ⅰ → 生命恢复+抗性Ⅰ → 生命恢复+抗性+速度Ⅰ（冷却 20 秒） |
- **Field Guide 图鉴**：166 道菜，**亲手做出来才解锁**图鉴条目（简餐/家常/珍馐三个分类页）。
- **料理署名**：出锅的菜会带上主厨签名，手持料理可用命令查验"这菜谁做的"。
- 厨师经验上限封顶 1.25×/1.5×/2×，高等级能力自动覆盖低等级。

### 🌾 新职业：农夫（tcth:farmer）
- **统一收获事件**：成熟作物无论是**打掉**还是**右键采摘**都算收获，支持原版 + 农夫乐事 + 万花筒烹饪作物。
- **四类奖励**：种田收获、动物繁殖、驯服动物、剪羊毛。
- 修了甜浆果右键采摘、辣椒动态判定、稻米移除型收获等实机问题；南瓜/西瓜奖励已移除（无法区分放置块与自然生长，防刷）。
