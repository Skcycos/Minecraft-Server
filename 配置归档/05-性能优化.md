# 05 · 性能优化类配置

> 配置根目录:`Server/config/`
> 涉及:ModernFix、FerriteCore、Lithium、ServerCore、spark、C2ME、NeoForge、FML。
> 整体状态:优化栈基本为默认/保守配置,稳定优先,未做激进调优。

---

## ModernFix(现代修复)

**配置文件**: `modernfix-common.toml` + `modernfix-mixins.properties`

- `blacklist_async_jei_plugins = ["jepb:jei_plugin"]` — 将 jepb 的 JEI 插件放回主线程加载(避免兼容问题)
- 因 mod 兼容被强制关闭的 mixin:`chunk_deadlock`(区块死锁修复)、`paper_chunk_patches`(paper 式区块补丁)、`cache_strongholds`(要塞缓存)、`release_protochunks`(原型区块提前释放)、`dynamic_resources`(动态资源)
- 其余 `mixin.perf.*` 优化默认全部开启;`stability_level = GA`

---

## FerriteCore(内存优化)

**配置文件**: `ferritecore-mixin.toml`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `compactFastMap` | `false` | 紧凑块状态映射关闭(换取兼容) |
| `useSmallThreadingDetector` | `false` | 小线程检测器关闭(官方标注高风险,默认关) |
| `blockstateCacheDeduplication` | `true` | 块状态缓存去重(主要省内存项,已开) |
| `dataComponentPatch` | `true` | 空数据组件补丁省内存 |
| `bakedQuadDeduplication` / `modelSides` / `modelResourceLocations` / `replaceNeighborLookup` / `replacePropertyMap` / `cacheMultipartPredicates` / `multipartDeduplication` | 全 `true` | 模型与方块状态类去重/精简全部开启 |
| `populateNeighborTable` | `false` | 不填充原版邻接表(最省内存,但 mod 直接访问时可能有风险) |

## ServerCore(服务器核心)

**配置文件**: `servercore/config.yml`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `features.autosave-interval-seconds` | `300` | 自动保存间隔 5 分钟 |
| `features.xp-merge-fraction` | `40` | 经验球合并概率约 2.5%(40 分之一) |
| `features.prevent-moving-into-unloaded-chunks` | `false` | 不阻止玩家走入未加载区块 |
| `lobotomize-villagers.enabled` | `false` | 村民省 tick 关闭 |
| `dynamic.enabled` | `false` | **动态性能调节(过载自动降 mobcap/视距)关闭**(预设档位已写好,随时可启用) |
| `breeding-cap.enabled` | `false` | 动物/村民繁殖上限关闭(预设 limit 32) |
| `activation-range.enabled` | `false` | **实体激活范围(最重要的省 tick 功能)主开关关闭**;已配置好各实体激活类型,随时可启用 |
| mobcap | MONSTER 70 / CREATURE 10 / AMBIENT 15 / WATER_CREATURE 5 | 分类刷怪上限 |

**配置文件**: `servercore/optimizations.yml`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `reduce-sync-loads` | `true` | 减少同步区块加载造成的卡顿 |
| `cache-ticking-chunks` | `true` | 每秒而非每 tick 更新 tick 区块列表,显著减少区块迭代开销 |
| `optimize-command-blocks` | `false` | 命令方块解析缓存未开 |
| `fast-biome-lookups` | `false` | 快速生物群系查找未开(保持群系边界准确) |
| `cancel-duplicate-fluid-ticks` | `false` | 保留原版每 tick 两次流体随机刻 |

## spark(性能分析)

**配置文件**: `spark/config.json`

- `backgroundProfiler = true` — 后台性能分析器开启(每 10 秒自动采样一轮,便于事后排查卡顿)

---

## C2ME(并行区块管理引擎)

**配置文件**: `c2me.toml` — 基本为默认(所有项为 `"default"`)

- 默认生效:密度函数编译加速世界生成、异步区块序列化、POI 可卸载(防内存泄漏)、流体后处理调度化、自动保存 ENHANCED 模式、原生库加速
- `noTickViewDistance.chunkSendingSpeedMultiplierPercentage = 200`(默认)— 区块发送速率 200%

> 该模组为 alpha 版本,是策划书列为「重点观察项」的性能组件,正式服锁定前需重点测试区块稳定性。

## NeoForge / FML(加载器)

**配置文件**: `neoforge-common.toml` + `neoforge-server.toml` + `fml.toml` — 基本为默认

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `removeErroringBlockEntities` / `removeErroringEntities` | `false` / `false` | 出错实体不自动移除(保持原版崩溃行为,稳妥) |
| `permissionHandler` | `"neoforge:default_handler"` | **权限处理器仍是 NeoForge 默认,未切换到 Paradigm** — Paradigm 的权限组不会自动接管 vanilla/其他 mod 命令 |
| `advertiseDedicatedServerToLan` | `true` | 服务器会出现在局域网列表(对公网服无实际影响) |
| `fml.versionCheck` | `true` | 全局版本检查开启 |
| `fml.disableOptimizedDFU` | `true` | DFU 优化已在服务端禁用 |

> ⚠️ 若要让 Paradigm 权限体系真正接管命令权限,需将 NeoForge 的 `permissionHandler` 指向 Paradigm 提供的处理器(参见 Paradigm 文档)。
