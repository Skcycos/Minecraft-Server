# 03 · 世界生成类配置

> 配置根目录:`Server/config/`
> 涉及:Terralith、Tectonic、Lithostitched、RoadWeaver。
> 世界生成模组为**世界级核心依赖**,正式开图前锁定版本与配置;开图后不得移除或替换。

---

## 泰拉瑞斯 (Terralith)

**配置文件**: `terralith.json`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `custom_structures` | `true` | 启用自定义结构(沙漠哨站、法师塔、废墟、地下城等) |
| `intro_message` | `true` | 进服显示 Terralith 介绍消息 |
| `recipe_changes` | `false` | 关闭对原版合成配方的改动 |
| `skylands` | `true` | 启用天空群岛(Skylands)生成 |
| `terrain_slabs` | `true` | 启用地形台阶(缓解悬崖楼梯感) |
| `vanilla_stone_gen` | `false` | 关闭原版石头替换生成(配合 Tectonic) |

---

## 地形构造 (Tectonic)

**配置文件**: `tectonic.json`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `mod_enabled` | `true` | 模组总开关,启用时改造地形生成 |
| `vertical_scale` | `1.125` | 垂直拉伸地形,海平面以上加倍即高度翻倍 |
| `min_y` / `max_y` | `-64` / `320` | 世界高度范围,与原版一致 |
| `ultrasmooth` | `false` | 关闭超平滑地形(避免深海/风袭群系生成异常) |
| `ocean_offset` | `-0.8` | 大幅偏置向海洋,海洋占比高 |
| `deep_ocean_depth` / `ocean_depth` | `-0.45` / `-0.22` | 深海海床约在海平面下 58 格、普通海洋约 28 格 |
| `monument_offset` | `-30` | 海底神殿下移 30 格以适应更深海洋 |
| `underground_rivers` | `true` | 河流遇山脉转入地下,可乘船穿山 |
| `river_lanterns` / `river_ice` | `true` / `false` | 地下河罕见悬挂灯笼;不生成冰 |
| `rolling_hills` | `true` | 平原生成平滑起伏丘陵 |
| `jungle_pillars` | `true` | 丛林生成可逾百格高的巨柱 |
| `lava_tunnels` | `true` | 世界底部罕见深层岩浆隧道 |
| `caves: cheese/spaghetti/noodle_enabled` | 全 `true` | 芝士/意面/面条三种洞穴均启用 |
| `carvers_enabled` | `true` | 旧式洞穴/峡谷刻蚀生成 |
| `ore_fix` | `false` | 不开启矿物深度修正(min_y 未改动,保持原版矿物分布) |

其余(biomes/continents_scale/erosion_scale/ridge_scale/flat_terrain_skew/islands 等)为默认数值,未特别调校。

## 道路编织 (RoadWeaver)

**配置文件**: `roadweaver/roadweaver.json`

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `roadsEnabled` | `true` | 全局道路生成开启 |
| `allowArtificial` / `allowNatural` | `true` / `true` | 人工铺装路与自然土径两种类型都启用 |
| `spawnCabinEnabled` | `true` | 出生点附近生成「出生小屋」 |
| `structurePrediction.enabled` | `true` | 启用结构位置预测(提前为村庄规划道路) |
| `structureWhitelist` | `["#minecraft:village"]` | 只预测/连接村庄类结构 |
| `villageRoadOffset` / `otherStructureRoadOffset` | `60` / `15` | 路到村庄 60 格、其他结构 15 格偏移 |
| `bridge.enabled` | `true` | 桥梁生成开启(水上架桥) |
| `tunnelEnabled` | `false` | 隧道生成关闭 |
| `roadWidth` | `3` | 路面宽度 3 格 |
| `roadSignsEnabled` | `true` | 路边路标启用 |
| `lampInterval` | `32` | 路灯间隔 32 格 |
| `slopeLimitEnabled` | `true` | 启用坡度限制,道路不在陡坡上 |
| `roadsideStructure.enabled` | `true` | 路边小结构(长椅、篝火、营地、墓碑等)生成,每路最多 3 个 |
| `roadsideVillage.enabled` | `true` | 路边村庄生成开启,`spawnChance=0.3`,每路最多 6 个 |
| 性能 | 初始 12 线程、最大并发 2 | 生成线程配置 |

**`roadweaver/presets/`(44 个预设)**: 结构统一为 `{id, name, type, materials[], slabMaterials[]}`。`type` 二选一:`ARTIFICIAL`(人工铺装,如 mud_road 泥砖路、aged_stone、stone_street)或 `NATURAL`(自然土径,42 个 `natural_*` 对应各群系,如 natural_plains 用 dirt_path/gravel/coarse_dirt)。无其它配置项。

**`roadweaver/structure_cache_overworld.json`**: 运行时生成维护的已登记结构清单(29 个原版结构 + roadweaver 17 个 + scguns 6 个 + spawn 5 个海岛 + terralith 27 个),并把这些模组结构挂入原版标签(如 fortified_village 加入 `#minecraft:village`),使原版地图/机制对模组结构生效。**无需手改。**
