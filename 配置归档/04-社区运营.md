## Open Parties and Claims(领地队伍)

**配置文件**: `openpartiesandclaims-server.toml`

**核心设置**:

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `permissionSystem` | `"prometheus"` | 权限系统走 Prometheus API |
| `primaryPartySystem` | `"argonauts_guilds"` | 首选队伍系统为 Argonauts 公会 |
| `autosaveInterval` | `10` | 数据每 10 分钟自动保存 |
| `maxPlayerGroups` / `playerGroupSpace` | `16` / `256` | 每玩家可建组数、组条目空间 |
| `playerSubConfigLimit` | `64` | 每玩家可创建的子领地数量上限 |

**队伍 `[parties]`**: `enabled = true`;成员/盟友上限 64/64;邀请上限 16;队伍沉寂 720 小时后删除(每 360 分钟检查一次);队伍聊天写入服务端日志。

**领地 `[claims]`**:

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `enabled` | `true` | 领地功能开启 |
| `partyOwnedClaims` | `false` | 队伍不整体持有领地(领地归队长个人) |
| `playerClaimsExpirationTime` | `8760` | 玩家沉寂 365 天后领地过期 |
| `playerClaimsConvertExpiredClaims` | `true` | 过期领地转为「过期领地」而非直接释放 |
| `maxPlayerClaims` | `500` | 每玩家最大领块数 |
| `maxPlayerClaimForceloads` | `10` | 每玩家最大强制加载块数 |
| `maxClaimDistance` | `5` | 领块距玩家最远 5 格 |
| `claimableDimensionsList` | `[]`(ALL_BUT) | 默认所有维度均可圈地 |
| `claimWelcomeMessages` | `true` | 进出领地显示欢迎语 |

**保护 `[protection]`**(较细的例外配置):
- 友好生物保护:`ALL_BUT`,例外仅 `minecraft:boat`;敌对生物保护:`ONLY`,列表空(默认不保护敌对实体)
- 强制放行:工作台交互、`minecraft:minecart`
- 可自助开放例外组 20+ 组:门/箱子/桶/末影箱/潜影盒/熔炉/漏斗/发射器/铁砧/切石机/磨石/制图台/讲台/锻造台/织布机/音符盒/床/信标/附魔台/作物破坏等
- 可破坏的实体:羊吃草、投掷物(药水/三叉戟/箭/末影珍珠/蛋/潜影贝子弹)
- 领地内禁用物品右键:`supplementaries:slingshot`;放行物品右键:`minecraft:firework_rocket`
- 假玩家:`[IntegratedTunnels]` 放行,ComputerCraft TurtlePlayer 排除
- `reducedBoatEntityCollisions = true` — 随机忽略船只碰撞检测提性能

## InControl(生物控制)

**配置文件**: `incontrol/spawn.json`(其余 11 个文件均为空数组 `[]`,无自定义规则)

| 规则 | 作用 | 目标 | 关键参数 |
|---|---|---|---|
| 规则 1 | 生成定稿阶段倍化血量 | 全部敌对生物 | `hostile=true`、`healthmultiply=2.5`、`result="default"` |
| 规则 2 | 生成定稿阶段倍化血量 | 全部生物(无过滤) | `healthmultiply=6.5`、`result="default"` |

> ⚠️ **重点确认项**:InControl 命中的规则按叠加语义生效,若两条规则同时命中敌对生物,血量可达基础值 ×2.5×6.5 = **×16.25**(推断,配置文件未明示叠加语义);非敌对生物为 ×6.5。请确认是否为设计本意,并配合 `entity_health_scale.js`(KubeJS)检查实际效果。

其余文件(`events/effects/loot/spawner/areas/phases/experience/breakevents/leftclicks/rightclicks/placeevents.json`)— 均为空,未配置。

## Paradigm(运营底座)

> 已中文化定制;以下为各模块要点。配置文件均在 `paradigm/` 下。

**`main.json`(模块总开关)**: 公告/MOTD/@提及/定时重启/自定义命令全启用;`forceCommandPriorityEnable = true`(Paradigm 命令覆盖其它 mod 同名根命令);`externalCommandPermissionMode = "deny_only"`(仅拦截显式拒绝);`telemetryEnable = true`(每 5 分钟匿名遥测);**全局出生点 `spawnX/Y/Z` 仍是占位值(0/64/0)**,需用 /setspawn 配置;`defaultLanguage = "en"`。

**`announcements.json`(公告)**: 聊天栏/动作栏/全屏标题/bossbar 四种公告均开启,每 30 分钟一条;前缀 `[Paradigm]` 蓝紫渐变;**含一条 `https://example.com` 占位链接,开服前需替换**。

**`chat.json`(聊天格式,已中文化)**: 管理频道「食韵筑家·管理」、私聊/群聊/进出服消息(/msg 中文收发)、首次进服欢迎语、自定义聊天格式(金色玩家名)全开启。

**`commands.json`**: 80+ 命令项全部 `true`,无禁用 — 命令全部开放,权限控制完全交给权限组。

**`cooldowns.json`**: home/back/spawn/warp/tpa/tpahere/tpaccept 冷却与前摇全部为 0(瞬移生效,无成本)。

**`motd.json`(已深度中文化)**: 中文欢迎页含服务器名、玩家等级/生命占位符、常用命令(/rules、/spawn 可点击)、玩家交流群 `903730159`(点击复制)、「主世界长期保留,不轻易重置」声明;服务器列表显示实际在线人数,最大展示 100。

**`restarts.json`(定时重启)**:
- `restartType = "Realtime"`,`realTimeInterval = [00:00, 06:00, 12:00, 18:00]` — **每天固定 4 次重启**(0/6/12/18 点)
- 重启前 1 小时起逐级倒计时(3600→1 秒);bossbar/聊天/标题三种警告全开,最后 60 秒播放警示音
- `defaultRestartReason` 为英文 `"The server is restarting!"`,**未汉化**

**`tablist.json`**: 自定义 Tab 列表启用,header/footer 中文(在线人数),按权限组权重降序、名字升序排序,5 秒刷新;`showPing = false`(不显示延迟)。

**`moderation-settings.json`**: 自定义封禁拒绝画面(原因/执行者/ID/到期时间);**申诉 URL 仍为占位地址 `https://example.invalid/...`,需配置真实申诉站**。

**`mentions.json`**: @提及启用,单人@冷却 30 秒、@everyone 冷却 60 秒;聊天/标题/副标题三种提醒全开。

**`holograms.json`**: 全息投影模块启用(默认视距 48)但**尚未配置任何全息内容**(`holograms = {}`)。

**`emojis.json`**: 55 个 emoji 快捷名映射,基本为默认符号集。

## Ecliptic Seasons(节气季节)

**配置文件**: `eclipticseasons-common.toml` — 季节系统为「视觉/氛围」型,玩法限制几乎全关

| 配置项 | 当前值 | 含义 |
|---|---|---|
| `LastingDaysOfEachTerm` / `InitialSolarTermIndex` | `7` / `4` | 每节气 7 天(4 季×6 节气=全年 168 天),从春分后第 4 节气开局 |
| `EnableSeasonalCrop` | `false` | **作物不受季节限制**(宽松) |
| `EnableCropHumidityControl` / `RestrictBoneMeal` | `false` / `false` | 湿度控制与骨粉限制关闭 |
| `EnableSeasonalBreed` / `EnableTimeBreed` / `EnableSeasonalBee` / `EnableSeasonalFishing` | 全 `false` | 动物繁殖、蜜蜂、钓鱼全无季节限制 |
| `HeatStroke` | `false` | 无夏季中暑效果 |
| `IceAndSnowMelt` / `IceAndSnow` | `false` / `false` | 物理冰雪生成/融化逻辑关闭 |
| `WaterFreezesInFrozenBiomes` / `SnowKeepInSnowyBiomes` | `true` / `true` | 保留原版冻原水域结冰与天然雪区不化 |
| `SnowyWinter` / `SnowyTree` | `true` / `true` | 冬季视觉积雪覆盖开启(氛围向) |
| `DynamicDaylightDuration` / `UseSolarWeather` / `RealWorldSolarTerms` | 全 `false` | 不动态调昼夜、不做分区天气、不与真实日期同步 |
| `ValidDimensions` | `["minecraft:overworld"]` | 季节仅在主世界生效 |

**结论**: 当前是「季节日历 + 节气播报 + 冬季视觉积雪」的轻量模式,不限制种植/养殖/钓鱼,对生存玩法几乎无实际影响,与养老服定位一致。
