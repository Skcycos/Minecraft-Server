=== Exposure: Space — external cosmic events ===

Drop your own night-sky events here (config/exposure_space/events/) as .json files —
WITHOUT rebuilding the mod. File name = event id (my_event.json -> exposure_space:my_event).
After editing run /reload in game.

See events/example_event.json.txt for a ready-made example — rename to .json to enable.
Force an event in game: /exposurespace event start exposure_space:my_event
